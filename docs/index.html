How to read this. The sample corpus is deliberately stacked with edge cases — vague one-liners, a multi-issue ticket, a non-English ticket, an angry email about $3.20 — so the automation rate you see here is far below what a real inbox produces. The point of the demo is not the rate, it is that every ticket the model was unsure about, or answered badly, ends up in the review queue with a reason attached instead of being silently misrouted.
